# POIZON SPB — Landing Page

Официальный промо-лендинг для сникер-шоурума и сервиса выкупа оригинальных кроссовок и стритвира с **Poizon (Dewu)** в Санкт-Петербурге.

## Особенности
- **Дизайн & Цвета:** Фирменная палитра Poizon с поддержкой **Тёмной** и **Светлой** темы (переключатель в шапке, запоминание в `localStorage`).
- **Автономность:** Все медиа-ресурсы встроены в Base64 — сайт работает без внешних зависимостей и сразу открывается на любом устройстве.
- **Прямая конверсия:** Продуманная воронка заказа через Telegram (`@Poizon_SaintP`).
- **Реальная фактура:** Фотографии команды в мерче, интерьер реального шоурума на Большой Московской 1-3, рейтинг 5.0 на Яндекс.Картах и честные отзывы.

## Локальный запуск
Просто откройте файл `index.html` в любом современном браузере.
